Funcionalidades

Coleta de dados de 50 entrevistados: Solicitando nome, idade e opinião sobre o atendimento.

Opções de avaliação:

1: EXCELENTE

2: BOM

3: RUIM

Validação de entradas:

Impede nomes em branco.

Garante a digitação de idades válidas (apenas números inteiros positivos).

Garante a seleção de uma opção de opinião válida (1, 2 ou 3).

🛠️ Tecnologias Utilizadas

Python

Estruturas de Repetição (for, while)

Estruturas de Decisão (if, elif)

Tratamento e Validação de Strings/Inteiros (.strip(), .isdigit())

🚀 Como Executar o Projeto

Passo a Passo

Executar o script:
No terminal ou prompt de comando, rode:

python pesquisa_de_opinião.py


(Substitua pesquisa_satisfacao.py pelo nome exato do arquivo do seu código).

Interação:
Responda aos questionamentos solicitados na tela para cada um dos 50 entrevistados. Ao final do loop, o relatório consolidado será impresso na tela.
